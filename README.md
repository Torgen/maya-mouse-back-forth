# maya-mouse-back-forth

Maya plugin to allow using the back/forward buttons on a 5 button mouse to
frame step back and forward respectively. If you hold the middle mouse button
while clicking the back/forward buttons, it will modify the current time
without updating the view, similar to middle-clicking on the timeline.

## Installation

* Clone the git repo anywhere on your computer.
* drag the `install.py` script from the root of that directory into a Maya window.
* Restart Maya.
* Open the plugin manager (Windows > Settings/Peferences > Plug-In Manager)
* Find `MouseBackForth.py` and check `Loaded` and `Auto load`.
